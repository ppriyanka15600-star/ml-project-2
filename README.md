 Diabetes Prediction using Machine Learning

📌 About the Project

This project predicts whether a person is likely to have diabetes based on medical data.
It uses Machine Learning algorithms to analyze patient features and provide predictions.

---

🎯 Problem Statement

Early detection of diabetes can help in better treatment and prevention.
This project aims to build a model that can predict diabetes using health-related attributes.

---

🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn

---

📊 Dataset

- Source: Pima Indians Diabetes Dataset

- Features:
 
  - Pregnancies
  - Glucose Level
  - Blood Pressure
  - Skin Thickness
  - Insulin
  - BMI
  - Diabetes Pedigree Function
  - Age

- Target:
 
  - 0 → No Diabetes
  - 1 → Diabetes

---

⚙️ Project Workflow

1. Data Collection
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Scaling
5. Model Training (Logistic Regression / Decision Tree / etc.)
6. Model Evaluation

---

▶️ How to Run the Project

pip install -r requirements.txt
python train.py

---

📈 Results

- Model Accuracy: 76.6%
- The model performs reasonably well in predicting diabetes based on input features.
